Visa GNOC Interview Preparation

Preparation for the Associate Network Analyst - Visa GNOC technical interview.

🎯 The goal

The initial interviewer advised that the priority is strong networking knowledge, with particular focus on:
* Networking fundamentals
* Cisco troubleshooting and CLI
* Network troubleshooting scenarios
* Automation
* ServiceNow / incident management

📚 Study Areas

1. Networking Fundamentals 
    * OSI & TCP/IP
    * Ethernet & MAC addresses
    * Switching & VLANs
    * IP addressing & subnetting
    * ARP
    * Routing & default gateways
    * DNS & DHCP
    * TCP/UDP
    * LAN/WAN

2. Cisco IOS 
    * show version
    * show ip interface brief
    * show interfaces
    * show mac address-table
    * show vlan brief
    * show arp
    * show ip route
    * CDP
    * show cdp neighbors
     
3. Troubleshooting 
    * Connectivity issues
    * Interface issues
    * Routing issues
    * VLAN issues
    * DNS issues
    * WAN/circuit issues
    * Latency & packet loss
     
4. Automation 
    * Network automation
    * Python
    * APIs
    * Monitoring & remediation
    * ServiceNow automation
     
5. ServiceNow & Experience 
    * Incident management
    * SLA & prioritisation
    * Escalation
    * Cummins networking examples
